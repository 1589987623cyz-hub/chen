# EX-SENSE 面罩 · 技术规格（给 Claude Code 读）

> RC5 Multi-State Mask · EX-SENSE「Feel beyond sight」造型。**96 片花瓣，每片对应一个菱形格，尖端朝上，覆盖在带面部起伏的壳上。**
> 本文件 + `params.json` / `tiles.json` / `pins.json` 是唯一几何来源。

## 0. 硬性规则

1. 所有几何都从 JSON 读取，或用 `reference/maskGeometry.js` 计算。**禁止手调坐标、禁止随机。**
2. 每个顶点都按同一个公式放置：`P = shellAt(U/a, V/b) + normal(U/a, V/b) * (relief(U, V) + offset)`，其中 `(U, V)` 是曲面参数坐标（mm），`relief` 是 §3.3 的面部起伏。
3. 单位是 **mm**。如果场景用米，只把根节点缩放 0.001。
4. 要改造型，就改 `generate.py` 顶部的参数，再运行 `python generate.py`（约 6 分钟，其中大部分是穿模检查，需要 numpy、scipy、scikit-image、matplotlib）。
5. 完成后跑一遍 §8 的验收。

## 2. 坐标系与总体尺寸

- +Y 向上，+Z 朝向观看者（面罩正面朝 +Z），+X 在观看者右侧。原点是壳外表面最前点，位于两眼之间。
- 壳体宽 **151.6**，高 **189.1**（Y 从 −91.9 到 +97.1），深 **67.2**。外圈花瓣尖端最多超出壳边 6 mm。

## 3. 基础壳

```
k(φ) = 1 − 0.25 · max(0, −sin φ)^1.4
x = 78·k·sinθ·cosφ     y = 105·sinφ     z = 88·(cosθ − 1)·cosφ + p(φ)
p(φ) = −20·(y/97)^2.2   (y ≥ 0)     p(φ) = −5·(−y/92)^2.2   (y < 0)     y = 105·sinφ
θ ∈ [−80°, 80°]   φ ∈ [−62°, 70°]
U = 78·θ   V = 105·φ          (θ, φ 为弧度)
```
- 法线 = ∂S/∂φ × ∂S/∂θ，用数值差分计算（ε = 1e-4），并保证 n.z > 0。壳厚 2.0，向内生长。壳体颜色 #dcbcb0，这样花瓣之间的缝隙不显黑。
- **外轮廓**：UV 平面里的超椭圆，`(|U|/104)^2.5 + (|V−6|/118)^2.5 = 1`。
- **开口**：两只眼是椭圆，中心 (±33, 12)，rx 20，ry 12.5，旋转 ∓8°（外眼角上扬）。鼻口是圆角三角形，顶点 (0, 8)，底边 y = −70，半宽 36，圆角半径 8。眼和鼻口用正视 2D 坐标定义，`params.outlines.openingsUV` 里已经换算成 UV。
- **侧面轮廓**：`p(φ)` 让中线接近人脸侧面，不再按椭球后收，这样面具才戴得上。
- **实现方式**：用 θ×φ 网格，至少 180×220 段。外轮廓和开口通过 UV 空间的 alphaMap 切出来，这样边缘精度不受网格疏密影响。

## 3.1 贴合检查

`generate.py` 用 `fitReference` 里的参考人脸检查贴合，壳内表面穿模或鼻翼放不进开口时会直接报错。参考人脸是**按常见成人比例估算的，不是扫描数据**，也不会出现在模型里。结果写入 `params.derived.fit`，当前最小间隙 4.39 mm，鼻翼每侧余量 1.97 mm。图纸 03 用红色虚线画出参考人脸的中线。

## 3.2 功能决定的形态

位置都写在 `generate.py` 顶部，用菱形格坐标 `[i, j]` 表示，即 `(U, V) = (i·12, j·14)`。

| 形态 | 功能 | 规则 |
|---|---|---|
| 8 个距离窗口 | SPACE | 每个反馈扇区一个，感知方向和面部感受到的方向一致，窗口轴线就是该点的壳面法线 |
| 1 个 UV 窗口 | UV | 额头顶端，朝上倾斜 23° |
| 进气口和出气口 | AIR | 右颊进气，左颊出气，让气流穿过颗粒物传感器 |
| 74 个贴肤触点 | 触感和冷热 | 见下文 |
| 4 个绑带槽 | 佩戴 | 太阳穴和下颌各一对，半径 3.5，长 20 |

花瓣自动避开传感器固定环（间隙 1.0）和绑带槽，销在这些位置也会被去掉。花瓣比传感器高，所以每个传感器的视野被限制在一个锥角内，见 `derived.petals.sensorViewDeg`，当前最小的是 UV 窗口 31.6°，距离窗口 34.3–51.1°。

**贴肤触点**：每片花瓣选一个 `anchorUV`，要求离花瓣边缘至少 2.5，且下方没有其他花瓣，杆才不会扎穿下层。杆半径 1.2，从花瓣底面穿过壳上半径 1.8 的孔，末端是硅胶垫。长度按该点到参考人脸的距离计算，静止时离皮肤 0.5，花瓣下压 1.5 时压入皮肤 1。面颊用半径 7 的大垫片承载冷热提示，其余用半径 3.5 的垫片。到人脸超过 26、或垫片会进入眼鼻开口、或找不到无遮挡位置的花瓣不设触点。垫片过近时，大垫片先缩小，再去掉较小花瓣上的触点，左右同步调整。当前触点长度 11.52–25.92 mm，大垫片 6 个。

**重要**：触点长度取决于估算的参考人脸。真实佩戴时必须按个人脸型重算或用不同长度的硅胶头补偿。

## 3.3 面部起伏

壳的外形再加一层起伏 `relief(U, V)`，最高 7.85 mm，存放在 `params.outlines.reliefUV`（步长 2 mm 的网格，双线性插值，Python 和 JS 结果相同）。由眉弓、鼻梁、鼻翼两侧、颧骨、下巴和额头隆起组成，靠近眼睛时降到 6%，眼睛就落在眼窝里。

起伏只增加高度，不向脸的方向压，所以壳、传感器、触点和销都跟着外移，贴合间隙只会变大。

## 4. 花瓣

### 4.1 生成规则（已算好，直接读 `tiles.json`）
- 在 UV 空间铺**菱形格**：单元宽 24、高 28，格点落在 U = 0 上。中缝把横跨中线的单元切成左右两块。按旧的裁切规则得到 96 个单元，每个单元提供编号、中心、扇区和分区。
- **每个单元一片花瓣**，最宽处落在单元中心，尖端朝上。从正面看偏离竖直方向不超过约 4°，朝外缘倾斜。
- 长 50、宽 28 是基准，再按单元面积和离面部中心的距离缩放，中心 0.95 倍，外缘 1.30 倍。当前长 16.0–60.5，宽 12.9–37.6。
- 尖端、根部、两侧边缘和弯曲的中线都会在开口、传感器固定环、绑带槽和中缝前停下。外圈尖端可以超出壳边 6 mm。

### 4.2 叠放
- 叠放顺序：从上到下、从外到内。下面的花瓣压在上面花瓣的根部，内侧压在外侧上。
- 所有花瓣共用一个斜面：向尖端每 mm 抬高 0.2，向外缘每 mm 抬高 0.09。这个斜面按菱形格坐标计算，所以两片重叠的花瓣处处高度差基本相同，不会交叉。
- 花瓣厚 0.8。同一扇区且同一分区的花瓣一起移动，顶面之间保持 1.0。不同组的花瓣，上层还要留出 1.5 行程，顶面之间保持 2.5。不够的地方才局部抬高。
- 最高点距起伏面 20.1，距基础壳面 22.6。

### 4.3 单片实体
- 网格 44×13。顶面在 `off`，底面在 `off − 0.8`，四周有侧壁，是封闭实体。
- 金色描边、叶脉和尖端金珠只用于显示，随花瓣一起移动，不在打印文件里。材料和工艺未定。

### 4.4 支撑销
- 半径 1.5，高 1.0，沿法线立在壳面上，位于菱形格顶点。传感器和绑带槽占用的格点不设销。销被花瓣盖住，从外面看不到。
- **销现在没有明确的结构作用，保留它们是为了不丢掉原来的安装位置。** 花瓣如何固定和驱动还要另行设计。

## 6.1 花瓣控制（配置器）

**外观和姿态**存在 `config.look`，不影响面具如何工作，协助者也可以修改：
- 颜色：配色方案、分区配色、色彩浓度、透明度、底壳颜色，金边、叶脉、金珠开关。
- 姿态：绽放（可分区设置）、错落、偏摆、大小。花瓣绕根部转动或缩放，绽放最大 14°，偏摆最大 12°。
- 动态：呼吸、波浪、涟漪、微风，可调速度和幅度。系统要求减少动画时不播放。
- 这些都只用于展示。实物花瓣只能向内移动，§8 的穿模检查只针对默认姿态。

**动作**存在 `config.motion`，会改变用户的感受，只能由用户本人修改，修改后要重新确认反馈设置：
- 内推行程 0.6–1.5 mm，可以按分区单独设置。
- 静音的花瓣列表，可以逐片或按分区、方向成组操作。静音的花瓣不参与反馈，但仍然打印。
- 按下节奏：同时按下，或层层压下。层层压下时叠放顺序靠下的花瓣先动，间隔 20–200 ms。

**限位**：`tiles.json` 里每片花瓣的 `beneath` 列出压在它下面的花瓣，以及它单独下压时能走多远。同一组花瓣之间只留了厚度和 0.2 的空气间隙，所以一片花瓣不能比它下面的花瓣多走超过这个距离。`limitTravel` 从叠放底层往上计算，所有动作（反馈、试按、静音、分区行程）都经过它。花瓣被挡住走不满行程时，配置器会提醒。

某个方向的可动花瓣少于 3 片时，配置器也会提醒。

## 7. 渲染设置

- `camera.near = 5`，`far = 2000`（单位 mm）。near 设得太小会出现深度闪烁和锯齿。
- `antialias: true`，`setPixelRatio(Math.min(devicePixelRatio, 2))`。
- 花瓣用半透明的 `MeshPhysicalMaterial`（`opacity 0.93`），颜色来自顶点色，`renderOrder` 按叠放顺序 `petal.rank`，半透明才能正确叠加。
- 不要用 `polygonOffset` 去掩盖穿插问题。叠层偏移已经保证不会穿插。

## 8. 验收

1. 所有顶点都没有 NaN。
2. 每片花瓣体积为正，且没有开放边和非流形边。参考实现实测：96/96 片通过。
3. 96 个菱形格各有一片花瓣，尖端朝上。
4. `derived.petals.rimCrossings` = 0：3D 检查里没有花瓣边缘穿过其他花瓣。`generate.py` 不满足时直接报错。
5. `derived.petals.pushedGap` ≥ 0：花瓣按下、下层不动时仍有间隙，当前 0.09。不满足时直接报错。
6. 每根触点杆下方都没有其他花瓣。
7. 每个扇区都有距离窗口和至少 3 个触点，触点垫片不进入眼鼻开口，左右对称。
8. 花瓣覆盖壳体的比例不低于 90%，当前 92.3%。
